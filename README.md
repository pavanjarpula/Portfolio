## 🎨 Design Philosophy

The visual language is inspired by **high-end editorial design** and **brutalist web aesthetics** — dark, minimal, intentional.

| Principle | Implementation |
|-----------|---------------|
| **Dark-first** | Near-black background (`#030303`) with layered surface hierarchy |
| **Gold as an accent** | `#D4AF37` used sparingly to draw the eye without screaming |
| **Typography-led** | Display font (serif italic) for headings, mono for technical labels |
| **Motion with purpose** | Every animation serves a UX function — no gratuitous effects |
| **Noise overlay** | Subtle CSS texture adds depth and warmth to flat surfaces |
| **Custom cursor** | CSS cursor replaced entirely for an immersive, brand-consistent feel |

### Color Palette

## ⚡ Feature Highlights

### 🖱️ Custom Cursor System
A full cursor replacement built in React. The cursor morphs and scales on hover over interactive elements (`a`, `button`, `[data-hover]`), giving the site a distinct, tactile feel.

### 🎥 Scroll-Driven Project Reel
The Projects section features a **dual-row horizontal reel** that animates as you scroll vertically. The two rows move in opposite directions using `useScroll` + `useTransform` from Framer Motion, ensuring all 4 projects are visible and explorable at any scroll depth — mathematically precise using `vw`-based offset calculations.

### ✨ Particle & Ambient Animations
- Floating gold accent particles around the hero portrait (5 staggered loops)
- Animated scan-line effect across the profile image
- Pulsing corner bracket decorations on the hero photo frame
- Radial glow orbs as ambient environment lighting

### 📜 Staggered Entrance Animations
Every section uses `useInView` to trigger **staggered Framer Motion animations** on scroll, with custom cubic-bezier easing `[0.22, 1, 0.36, 1]` for a natural, spring-like feel.

### 🎞️ Film Grain Texture
A CSS noise overlay renders across the entire page at low opacity, adding a tactile, analog warmth to the digital interface.

### 📱 Responsive Marquee
A continuously scrolling tech ticker bar separates the Hero and About sections, communicating the full breadth of skills at a glance.

### 📬 Contact Form with mailto Integration
The contact form collects Name, Email, and Message, then composes a pre-filled `mailto:` link — no backend required, no third-party form service, instant delivery.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

```bash
node  >= 18.0.0
npm   >= 9.0.0
```

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/pavanjarpula/portfolio.git
cd portfolio
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the development server**
```bash
npm run dev
```

The site will be live at `http://localhost:5173` with Hot Module Replacement enabled.

| `npm run build` | Create optimized production bundle in `/dist` |

| `npm run lint` | Run ESLint across the entire codebase |

## 🧩 Sections Breakdown

### 1. `Hero.jsx` — First Impressions Matter
The full-viewport hero is the handshake. It renders two columns:
- **Left**: Staggered title (`Software Developer`, `& AI / Data Engineer`), bio paragraph, and two CTAs (*Selected Work*, *Get in Touch*)
- **Right**: Profile photo in a decorated frame with animated corner brackets, floating particles, and a scan-line effect

> The photo transitions from 40% greyscale to full colour on hover — a subtle nod to coming alive.

### 2. `Marquee.jsx` — The Ticker
An infinitely scrolling horizontal band listing key technologies. Acts as a visual break between Hero and About while conveying breadth of skills at a glance.

### 3. `About.jsx` — The Human Behind the Code
Two-column layout with:
- A heading, IIT Kharagpur badge, key stats (3+ yrs, 10+ projects, 5+ tech), and social links on the left
- A bio paragraph and a 4-cell info grid (Role, Location, Availability, Passion) on the right

### 4. `Skills.jsx` — The Armoury
Five skill category cards rendered in a responsive flex wrap:
- **Languages** — C/C++, JavaScript, Python, HTML/CSS, TypeScript
- **Frontend** — React, Tailwind, Redux, Framer Motion, Next.js
- **Backend** — Node.js, Express, REST APIs, JWT/OAuth, GraphQL
- **Database & Tools** — MongoDB, Git, Postman, VS Code, Docker
- **Data Science** — NumPy, Pandas, Matplotlib, Seaborn, LangChain, RAG

Each card has a custom inline SVG icon per technology, crafted from scratch.

### 5. `Projects.jsx` — The Reel ⭐
The technical crown jewel. A scroll-driven **dual-row carousel** where:
- Row 1 (`[01, 02, 03, 04]`) slides left as you scroll down
- Row 2 (`[03, 04, 01, 02]`) slides right (opposite direction)
- At any scroll position, all 4 projects appear across both rows — guaranteed by precise `vw`-based offset math

Each card features a coloured gradient top-bar, glow orb, metrics badges, and a GitHub link.

### 6. `Achievements.jsx` — Proof of Work
Three-column competitive programming cards (LeetCode, Codeforces ×2) + a split layout of Certifications (3 cards) and an Education timeline.

### 7. `Contact.jsx` — The Handoff
A centred contact form (no backend — `mailto:` magic) + 4-column social grid (Email, LinkedIn, GitHub, Phone) + a minimal footer.

## 🔧 Customization Guide

### Updating Personal Info
Edit the constants in the relevant section files:

```jsx
// src/sections/Hero.jsx — Hero headline & bio
<motion.h1>Software Developer</motion.h1>
<p>Hi, I'm Jarpula Pavan...</p>

// src/sections/About.jsx — Stats, bio, social links
const stats = [
  { value: '3+', label: 'Years Coding' },
  ...
];

// src/sections/Contact.jsx — Social handles & email
const socials = [
  { label: 'Email', value: 'your@email.com', href: 'mailto:your@email.com' },
  ...
];
```

### Adding a Project

Open `src/sections/Projects.jsx` and add an entry to the `projects` array:

```jsx
const projects = [
  {
    id: '05',
    title: 'Your Project',
    subtitle: 'A short tagline',
    description: 'What it does and why it matters.',
    tags: ['React', 'Node.js', 'MongoDB'],
    color: '#YOUR_HEX',        // Card accent color
    accent: '#YOUR_HEX2',      // Gradient secondary
    github: 'https://github.com/you/project',
    metrics: ['Key Metric 1', 'Key Metric 2', 'Key Metric 3'],
    year: '2025',
  },
  // ...
];
```

### Changing the Color Accent

All theme colors are CSS custom properties in `src/index.css`. Change `--accent` to rebrand the entire site:

```css
:root {
  --accent: #d4af37;      /* Gold — change this for a new theme */
  --bg: #030303;
  --surface: #0d0d0d;
  --text: #f0ece4;
  --text-muted: #7a7570;
  --text-subtle: #4a4540;
  --glow: rgba(212, 175, 55, 0.08);
}
```

### Swapping the Profile Photo

Replace `public/profile.jpg` with your own image. For best results:
- Aspect ratio: **4:5** (portrait)
- Resolution: **800×1000px** minimum
- Face centered, slightly upper half of frame

## 📦 Deployment

### Deploy to Vercel (Recommended)

The fastest path to production:

```bash

npm i -g vercel

# Deploy (follow the prompts)
vercel

vercel --prod

# → dist/ folder ready for Netlify, GitHub Pages, S3, Cloudflare Pages, etc.
```

No environment variables required. The contact form uses `mailto:` — fully static, zero backend, zero config.
